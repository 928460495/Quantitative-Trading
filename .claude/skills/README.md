# superpowers 技能

来自 [obra/superpowers](https://github.com/obra/superpowers) v7.0.1（提交 `2ce8aa15d05bd57213e6f746f953aafb7ded7a8b`），MIT 许可，见 `LICENSE-superpowers`。原样拷贝 `skills/` 目录，没有改动。

官方装法是 Claude Code 插件（`/plugin install superpowers@claude-plugins-official`），插件会在每次会话开始时用钩子注入 `using-superpowers`。云端会话里改为放进仓库，由 `CLAUDE.md` 提示先读它。本项目怎么用这些技能，见仓库根目录的 `CLAUDE.md`。
