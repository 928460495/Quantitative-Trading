# 单因子检验汇总

- 样本：csi300 历史成分，train 段 2010-01-01 ~ 2018-11-29（段尾去掉 21 个交易日），2166 个交易日，过滤后保留 94.0% 的样本；未做行业和市值中性化
- 主指标：5 天持有期 RankIC，t 值经 Newey-West 调整（滞后 4 阶）
- 门槛：t 值 > 3；方向反了的年份不超过一半；扣成本后做多一侧超额 > 0。相关性去冗余在第 4 个 PR 做
- 入场日收盘涨跌幅 ≥ 9.5% 视为买不进，对 20% 涨跌停的创业板和科创板偏保守
- 还没有 ST 标记，ST 股没有剔除（沪深300 里很少）
