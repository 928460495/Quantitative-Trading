# 单因子检验汇总

- 样本：csi300 历史成分，train 段 2010-01-01 ~ 2018-11-29（段尾去掉 21 个交易日），2166 个交易日；能买入的样本占 94.0%；已对申万一级行业（当天不足 5 只的行业合并为“其他”）和对数流通市值做中性化；行业和市值都有数据的样本占 98.1%，其中 6.7% 的市值缺股本数据、用对数 20 日平均成交额估算（估算值与真实值的每日相关系数平均 0.54、最低 0.20）
- 结果：打分因子 3 个，排雷因子 1 个，淘汰 3 个
- 主指标：5 天持有期 RankIC，t 值经 Newey-West 调整（滞后 4 阶）
- 打分因子：t 值 > 3；方向反了的年份不超过一半；按实际交易规则（每日调仓、持仓 30、缓冲 30/90）扣成本后做多超额 > 0
- 排雷因子：t 值 > 3；方向反了的年份不超过一半；最低组年化超额 < 0 且 t 值 < -3。用法是剔除得分最差的股票，不参与打分
- 相关性去冗余在第 4 个 PR 做
- 入场日收盘涨跌幅 ≥ 9.5% 视为买不进，≤ -9.5% 视为卖不掉；对 20% 涨跌停的创业板和科创板偏保守
- 还没有 ST 标记，ST 股没有剔除（沪深300 里很少）
