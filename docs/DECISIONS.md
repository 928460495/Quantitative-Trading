## 变更记录

### 2026-10-25：调仓改为每日，补充方法论

在第一批单因子结果（每周口径，7 个因子全部被成本门槛淘汰）出来之后改动，原因：成本门槛按"最高 20% 每期全换"计算，比实际交易规则严得多；同时参考了 Novy-Marx & Velikov (2016)、Gârleanu & Pedersen (2013)、DeMiguel 等 (2020)、华泰《因子合成方法实证分析》(2019)、López de Prado 的方法论。

| 项目 | 原来 | 现在 |
|---|---|---|
| 调仓 | 每 5 个交易日；稳健性检验分 5 份错开 | 每日决策、慢速交易 |
| 标签 | 5 天 | 仍是 5 天；IC 衰减扩展到 1、2、3、5、10、20 天 |
| 持仓 | 30 只，每周最多换 6 只 | 30 只，缓冲 30/90（进前 30 才买，掉出 90 才卖）；对照 30/60、30/120 |
| 成本门槛 | 最高 20% 每期全换 | 按实际交易规则模拟（每日、持仓 30、缓冲 30/90） |
| 排雷因子 | 无 | t > 3、方向稳定、最低组年化超额 < 0 且 t < -3；用法为剔除最差 20%（对照 10%），不参与打分 |
| 回归法 | 无 | 每日横截面回归的因子收益率与 NW t 值，作参考 |
| 试验日志 | 无 | `reports/trials.jsonl`，按配置哈希去重；第 5 个 PR 计算通缩夏普比率 |
| 合成顺序 | 等权 → ICIR → 线性 → LightGBM | 等权 → ICIR → 最大化 ICIR → 线性 → LightGBM；升级标准为验证段上按实际交易规则扣成本后的做多超额 |
| 信号平滑 | 无 | 只在合成阶段试 3 天、5 天，计入试验日志 |
| 回测策略 | TopkDropout | 自写缓冲规则策略；对照基准 Alpha158 + LightGBM 用同一规则交易；附 TopkDropout 参考 |

上面"研究设计"和"回测"两节里的旧条目以本表为准。

### 2026-10-25：组合模拟的超额基准

拆解发现，第二天收盘涨停、买不进的股票之后一天的平均收益很高；把它们算进基准，基准每年高出约 4.7 个百分点，而且对所有因子都一样。

决定：单因子筛选的门槛，超额相对**当天有打分、且第二天能买进的股票**等权平均；相对**所有有打分的股票**（含买不进的）的超额作为参考列一起报告。买不进涨停股的真实损失，由最终测试里"相对沪深300 指数"的那一条体现。改口径后的重跑计入试验日志（配置里多了 `benchmark` 字段）。

### 2026-10-26：中性化的两处细节

数据分析见 `docs/DATA_NOTES.md`。

| 问题 | 决定 |
|---|---|
| 当天股票很少的行业（2917 天里 2409 天最小行业只有 1 只，残差会被吸收成 0） | 每天把不足 5 只的行业合并成"其他"组；"其他"组不设哑变量（不单独估计行业效应，只控制市值），否则"其他"组本身只有一两只时同样会被吸收 |
| 巨潮和新浪都没有退市股的股本（70 只，约占样本 4.9%） | 用当天"对数流通市值 ~ 对数 20 日平均成交额"的横截面回归估算；估算值与真实值的相关性写进报告，太低（< 0.8）时再讨论是否改为全部用成交额 |

### 2026-10-26：退市股市值估算质量不达标时的处理

实测估算值与真实值的每日相关系数平均 0.54（约定门槛 0.8）。对照试验（缺市值改用当天平均值）显示 RankIC、t 值几乎不变，只有扣成本后贴近 0 的 pv_corr20 在打分和排雷之间切换。决定：**保留成交额估算**，在报告里写明估算质量；pv_corr20 标为"临界"，到因子合成阶段由验证段检验是否有用。
